📊 Student Performance Analytics (Excel Project)

📌 Project Overview
This project analyzes student academic performance using Microsoft Excel.
The goal is to identify key factors affecting student success, such as attendance, internet quality, and burnout level.

📁 Dataset Description
The dataset contains student records with the following features:

Student ID– Unique identifier for each student
Attendance Percentage– Level of class participation
CGPA – Academic performance indicator
Internet Quality – Quality of internet access (Good/Poor)
Burnout Level – Student stress level (Low/High)
Grades – Overall performance category (Low/Medium/High)

🛠 Tools Used
* Microsoft Excel
* Pivot Tables
* Data Cleaning Techniques
* Charts & Dashboard Visualization

📊 Analysis Performed
* Data cleaning and formatting
* Performance comparison based on attendance
* Relationship between CGPA and burnout level
* Impact of internet quality on student grades
* Dashboard creation for visual insights

📈 Key Insights
* Higher attendance generally leads to better academic performance
* Students with good internet access tend to perform better
* High burnout levels can negatively affect CGPA
* Performance varies significantly across different student groups

📊 Dashboard
The project includes an interactive Excel dashboard for
* Monitoring student performance
* Comparing key metrics
* Visualizing trends and patterns
  
🎯 Purpose of the Project
This project demonstrates practical data analysis skills using Excel and provides insights that can help improve student academic outcomes.
